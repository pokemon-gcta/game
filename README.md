# Pokémon GBA Game

A Game Boy Advance style Pokémon game built with modern web technologies.

## Features

- 🎮 GBA-style pixel graphics and gameplay
- 🗺️ Tile-based world exploration
- 👾 Pokémon capture and battles
- ⚙️ Turn-based combat system
- 🎨 Retro aesthetic with smooth animations

## Tech Stack

- **Engine**: Phaser 3 (HTML5 game framework)
- **Graphics**: Pixel art sprites and tilesets
- **Language**: TypeScript/JavaScript

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
src/
├── scenes/           # Game scenes (Menu, Overworld, Battle, etc.)
├── entities/         # Player, NPCs, Pokémon
├── systems/          # Game logic (Battle, Inventory, etc.)
├── assets/           # Sprites, tilesets, audio
└── types/            # TypeScript type definitions
```
